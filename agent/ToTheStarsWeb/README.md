# 向着星 Web MVP · 每日委托计划系统

这是从原 PySide6 桌面版改造而来的本地单用户 Web MVP：Python FastAPI 后端 + React 组件化前端 + SQLite 本地数据库。

## 运行方式

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

启动后浏览器会自动打开：`http://127.0.0.1:8765`

API 文档：`http://127.0.0.1:8765/docs`

## 数据位置

主数据库：`data/growth_system.db`

启动备份：`backups/backup_YYYYmmdd_HHMMSS.db`

日志/导出目录：`logs/`、`exports/`

## 从旧版迁移

将旧版 `ToTheStars/ToTheStars/data/growth_system.db` 复制到本项目 `data/growth_system.db`。本项目启动时不会覆盖已有数据库；只会执行安全的 `CREATE TABLE IF NOT EXISTS` 和少量兼容性 `ALTER TABLE ADD COLUMN`。

首次启动前建议手动备份一份。程序启动时会在写入补结算之前自动生成启动备份。

## 已实现模块

- React 前端：侧边导航、组件化页面、统一弹窗/Toast、卡片式 RPG 视觉、无构建步骤即可本地运行。
- 每日委托：创建、编辑、删除、完成/取消完成、必要委托、日常委托、难度点数。
- 普通结算与日终结算：防重复入池、完成归档、未完成顺延、状态奖励。
- 钱包与点数流水：历练点、成长点、奖励购买扣点。
- 状态追踪：每日状态记录，日终发放 0.5 历练点且防重复。
- 假期设置：日期范围、取消、假期结算规则。
- 传说任务：指标进度、完成后发放成长点且防重复、归档。
- 奖励商店：创建、编辑、购买、扣点减库存、待出库/确认出库、售空、归档。
- 番茄钟：倒计时设置、开始、暂停、继续、取消、完成结算、专注事件入库、今日专注记录。
- 日程表：一周表格（每格 4 小时、今日高亮）与日时间轴（04:00 → 次日 04:00，精确到分钟）双视图；可把每日委托排进时间轴，也可添加自定义计划；时间重叠的片段自动分行错开，点击片段可随时编辑标题、内容与时间段。
- 统计复盘：完成率、结算记录、点数流水、状态、分类、传说进度表格、专注总时长、每日专注图表和专注事件表。

## 与 BetterAgent 联动（可选）

本应用可以与数字人项目 **BetterAgent**（独立运行的另一套服务）双向联动：右下角出现「和数字人说话」气泡，侧边栏多出「AI 活动」页；数字人可以在你授权范围内读取生活数据、经你确认后写入，并在合适时机主动提醒。**不配置则现有功能零变化。**

### 开启方式

在启动向着星之前设置环境变量（两套应用都在本机运行）：

```bash
# Windows PowerShell
$env:AGENT_WS_TOKEN="<BetterAgent .env 里的 WEBGATEWAY_TOKEN>"
# macOS / Linux
export AGENT_WS_TOKEN="<BetterAgent .env 里的 WEBGATEWAY_TOKEN>"
```

- `AGENT_WS_TOKEN`：必填。与 BetterAgent 根目录 `.env` 的 `WEBGATEWAY_TOKEN` 保持一致；不设置时 `GET /api/agent/chat-config` 返回 `enabled: false`，气泡不渲染。
- `AGENT_WS_URL`：可选，默认 `ws://127.0.0.1:8080/ws`。
- `AGENT_CHAT_ID`：可选，默认 `1001`；决定气泡对话在数字人侧的记忆会话。

权限与主动策略（数字人能读什么、能改什么、什么时候可以主动开口）在 **BetterAgent** 侧配置：设置 → 生活数据（向着星），或直接改 `config/config.yaml` 的 `integration.tothestars`。默认最小权限：委托/日程可读写（写入仍需逐次确认）、传说任务与点数只读、日记摘要问起才读、日记正文完全不可见。

### 联动接口（本机）

| 接口 | 说明 |
|---|---|
| `GET /api/agent/snapshot` | 今日生活快照（委托/日程/传说/点数/日记摘要），供数字人读取 |
| `GET /api/agent/audit` | AI 操作流水，供「AI 活动」页展示 |
| `POST /api/agent/audit/{id}/undo` | 撤销一条可撤销的 AI 操作 |
| `GET /api/agent/chat-config` | 气泡连接参数（未配 token 时 `enabled=false`） |

所有写接口都接受可选的 `X-Actor` 头：`companion`（数字人，会在「AI 活动」页标记来源）或默认 `me`（网页操作）。审计与撤销仅针对数字人写入；网页自身操作不进入该页面。全部通信仅在 `127.0.0.1`，没有云端账户。

## 注意

本项目为本地单用户工具，仅监听 `127.0.0.1`，不需要联网账户。前端已改为 React API 组件化实现，静态资源位于 `frontend/index.html`、`frontend/js/react-app.js`、`frontend/js/react-lite.js`、`frontend/css/react-polish.css`，无需 npm 构建即可运行。前端所有核心业务判断均来自后端 API。

## 手动验收清单

1. 删除 `data/growth_system.db` 后运行 `python main.py`，应自动创建空数据库。
2. 放入旧版数据库后运行，旧数据应可读取且不会被覆盖。
3. 创建 A/B/C/D 四个每日委托，点数应为 1/2/3/4。
4. 普通日不足 4 点或必要委托未完成时，普通结算不入池并解释原因。
5. 普通日满足条件时，普通结算入池；重复点击不重复入池。
6. 已入池委托取消完成时，后端拒绝并提示。
7. 假期日即使不足 4 点也允许已完成委托入池。
8. 保存状态后日终结算，发放 0.5 历练点且不重复。
9. 传说任务所有指标完成后，成长点只发放一次。
10. 奖励购买应扣点、减库存、写购买记录和点数流水，并进入待出库状态。
11. 在奖励商店的“出库状态”页确认出库后，奖励卡片应变灰并排到末尾。
12. 勾选日常委托后，完成并日终结算时，次日应自动生成一份新的未完成委托。

13. 进入“番茄钟”，应能设置分钟、开始、暂停/继续、取消；自然完成后保存专注事件并在今日记录与统计复盘中出现。
14. 打开“统计复盘”，应看到专注统计面板、每日专注柱状图与专注事件记录表。
15. 打开“日程表”，默认显示本周表格：每格约 4 小时，今天是高亮列，点击列头进入当天时间轴。
16. 在时间轴点“添加委托计划”，选择当天的每日委托并填写开始/结束时间（可精确到分钟），片段应出现在对应时段，预览只显示标题。
17. 添加两个时间重叠的计划，应自动分成两行错开显示，后开始的片段位于先开始片段的上一行。
18. 添加一条 23:30 → 00:30 的计划，应同时出现在“夜晚”和“深夜”两格，并跨越时间轴的 00:00 刻度。
19. 点击委托片段打开详情：修改标题或内容后保存，每日委托页的委托标题/描述应同步被修改；修改自定义计划则不影响任何委托。
20. 删除未完成的每日委托后，其时间轴计划应保留内容但变为“自定义计划”颜色；日终结算顺延的委托，其计划应一起顺延到次日。
21. 不设置 `AGENT_WS_TOKEN` 时刷新页面：右下角没有气泡。设置后重启：气泡出现，发送一句话能收到数字人的流式回复。
22. 「AI 活动」页：数字人写入过的记录带「数字人」来源标记，点击撤销后对应数据恢复，并出现一条“已撤销”记录。
